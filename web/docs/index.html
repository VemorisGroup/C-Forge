C-Forge v3.1.0

Un lenguaje de programación moderno, expresivo y listo para producción.

🚀 Expressivo

Sintaxis limpia en español. Pattern matching, closures, async/await, generics.

🏭 Production-ready

73+ módulos stdlib. Banco, videojuegos, ML/IA, HTTP, WebSockets, crypto.

🔧 Tooling completo

LSP para VSCode/Neovim, debugger DAP, type checker, benchmarks, BDD testing.

📦 Ecosistema

Gestor de paquetes cfpkg, playground online, documentación, REPL interactivo.

¿Por qué C-Forge?

C-Forge nació con una misión clara: crear un lenguaje de programación que sea tan potente como Java, C++ o C#, pero con una sintaxis más expresiva y un ecosistema moderno desde el primer día.

// Tu primer programa en C-Forge
funcion saludar(nombre: texto): texto {
    retornar "¡Hola, " + nombre + "! 👋"
}

sea mensaje = saludar("Mundo")
mostrar(mensaje)

// Pattern matching
match (mensaje) {
    caso m si (longitud(m) > 10) { mostrar("Mensaje largo: " + m) }
    caso m { mostrar("Corto: " + m) }
}

Características principales

  • Tipado gradual — tipos opcionales, inferencia automática
  • Pattern matching — match/caso con literales, bind y guards
  • OOP completa — clases, herencia, interfaces, abstractas, modificadores de acceso
  • Async/Await — programación asíncrona nativa
  • Closures y lambdas — funciones de primera clase
  • 73+ módulos stdlib — matemáticas, red, crypto, ML, videojuegos, bancos
  • LSP completo — autocompletado, hover, ir a definición, refactoring
  • Debugger DAP — breakpoints, step-by-step, inspect variables
  • BDD Testing — describir/cuando/entonces con mocks y spies

Instalación

Requisitos

  • Sistema operativo: Linux, macOS, Windows (WSL)
  • C++20 compatible (GCC 12+, Clang 14+, MSVC 2022+)
  • Python 3.10+ (para herramientas)

Desde código fuente

git clone https://github.com/VemorisGroup/C-Forge.git
cd C-Forge

# Compilar el intérprete
g++ -std=c++20 -O2 -o cforgev cforgev.cpp \
    -lcrypto -lpthread -ldl -DCFV_WITH_OPENSSL

# Verificar instalación
./cforgev --version

Configurar CFORGE_STDLIB

# Agregar a ~/.bashrc o ~/.zshrc
export CFORGE_STDLIB="/ruta/a/C-Forge/stdlib"
export PATH="$PATH:/ruta/a/C-Forge"

Instalar herramientas Python

pip install cforgev

Esto instala: cftype, cfbench, cfpkg, cfgen, cfmigrate, y el servidor LSP.

Extensión VSCode

cd vscode-extension
npm install
npm run compile
# Luego instala el .vsix desde la UI de VSCode
💡 Tip: Después de instalar la extensión, configura cforge.interpreterPath y cforge.stdlibPath en tu settings.json de VSCode.

Control de flujo

Condicionales

// si / sino_si / sino
si (temperatura > 30) {
    mostrar("Calor")
} sino_si (temperatura > 20) {
    mostrar("Templado")
} sino {
    mostrar("Frío")
}

Bucles

// mientras
sea i = 0
mientras (i < 10) {
    mostrar(a_texto(i))
    i = i + 1
}

// para...en (lista)
para fruta en ["manzana", "pera", "uva"] {
    mostrar(fruta)
}

// para...en (rango)
para n en rango(0, 100, 2) {  // 0, 2, 4, ..., 98
    // procesar n par
}

// romper y continuar
para item en items {
    si (item == "stop") { romper }
    si (item == "skip") { continuar }
    procesar(item)
}

Pattern Matching

C-Forge incluye un sistema de pattern matching potente con soporte para literales, bind de variables y guards (guardas).

Sintaxis básica

match (expresion) {
    caso patron1 { bloque1 }
    caso patron2 si (guarda) { bloque2 }
    caso _ { bloque_defecto }
}

Tipos de patrones

// Literal numérico
match (codigo_http) {
    caso 200 { mostrar("OK") }
    caso 404 { mostrar("No encontrado") }
    caso 500 { mostrar("Error servidor") }
    caso _ { mostrar("Otro código") }
}

// Literal de texto
match (comando) {
    caso "run" { ejecutar() }
    caso "stop" { detener() }
    caso "help" { mostrar_ayuda() }
    caso _ { mostrar("Comando desconocido") }
}

// Bind de variable
match (valor) {
    caso n si (n < 0) { mostrar("negativo: " + a_texto(n)) }
    caso n si (n == 0) { mostrar("cero") }
    caso n si (n > 1000) { mostrar("muy grande: " + a_texto(n)) }
    caso n { mostrar("positivo: " + a_texto(n)) }
}

// Nulo
match (resultado) {
    caso nulo { mostrar("sin resultado") }
    caso v { mostrar("resultado: " + a_texto(v)) }
}

// Booleano
match (condicion) {
    caso verdadero { activar() }
    caso falso { desactivar() }
}

Clases y Programación Orientada a Objetos

Clase básica

clase Rectangulo {
    privada ancho: numero
    privada alto: numero

    constructor(ancho: numero, alto: numero) {
        este.ancho = ancho
        este.alto = alto
    }

    publica funcion area(): numero {
        retornar este.ancho * este.alto
    }

    publica funcion perimetro(): numero {
        retornar 2 * (este.ancho + este.alto)
    }

    publica funcion escalar(factor: numero): Rectangulo {
        retornar nuevo Rectangulo(este.ancho * factor, este.alto * factor)
    }
}

sea r = nuevo Rectangulo(10, 5)
mostrar("Área: " + a_texto(r.area()))
mostrar("Perímetro: " + a_texto(r.perimetro()))

Herencia

clase Forma {
    publica nombre: texto
    constructor(nombre: texto) { este.nombre = nombre }
    publica funcion area(): numero { retornar 0 }
}

clase Circulo hereda Forma {
    privada radio: numero

    constructor(radio: numero) {
        super("Círculo")
        este.radio = radio
    }

    publica funcion area(): numero {
        retornar 3.14159 * este.radio * este.radio
    }
}

sea c = nuevo Circulo(5)
mostrar(c.nombre + " área: " + a_texto(c.area()))

Interfaces

interfaz Serializable {
    funcion serializar(): texto
    funcion deserializar(data: texto): nulo
}

interfaz Comparable {
    funcion comparar(otro: cualquiera): numero
}

clase Producto implementa Serializable {
    publica nombre: texto
    publica precio: numero

    constructor(nombre: texto, precio: numero) {
        este.nombre = nombre
        este.precio = precio
    }

    publica funcion serializar(): texto {
        retornar json_serializar({"nombre": este.nombre, "precio": este.precio})
    }

    publica funcion deserializar(data: texto): nulo {
        sea obj = json_parsear(data)
        este.nombre = obj["nombre"]
        este.precio = obj["precio"]
    }
}

funcion safe_parse(s: texto): mapa {
    intentar {
        sea n = a_numero(s)
        retornar {"ok": verdadero, "valor": n}
    } capturar (e) {
        retornar {"ok": falso, "error": a_texto(e)}
    }

sea r = safe_parse("42")

BDD (bdd.cfv)

importar "bdd"

describir("Sistema de login", funcion() {
    sea usuario = {}
    sea token = ""

    antes_de(funcion() {
        usuario = {"nombre": "Ana", "password": "secret123"}
    })

    cuando("el usuario existe y la contraseña es correcta", funcion() {
        antes_de(funcion() {
            token = autenticar(usuario["nombre"], usuario["password"])
        })

        entonces("devuelve un token válido", funcion() {
            esperar_no_nulo(token)
            esperar_tipo(token, "texto")
        })

        y("el token tiene más de 20 caracteres", funcion() {
            esperar_mayor(longitud(token), 20)
        })
    })

    cuando("la contraseña es incorrecta", funcion() {
        entonces("lanza un error de autenticación", funcion() {
            esperar_error(funcion() {
                autenticar(usuario["nombre"], "contraseña_incorrecta")
            })
        })
    })
})
